# Shipping, address changes and cancellations

## Delivery times
Standard shipping takes 3 to 6 business days after the order ships. Orders usually ship within 2 business days of being placed.

## Changing the address
The shipping address can be changed only while the order is still processing. Once an order has shipped we cannot redirect it. The customer can refuse the parcel or return it after delivery.

## Cancelling an order
An order can be cancelled only while it is still processing. A cancelled order is refunded in full automatically. Once an order has shipped it cannot be cancelled, but it can be returned after delivery under the returns policy.

## Lost parcels
If tracking shows no movement for 10 business days, a supervisor opens a carrier claim. Support agents cannot refund an order that has not been delivered; escalate it.
